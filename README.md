The single sentence that could have replaced an entire pointless meeting, judged head to head in pairs. Free to enter.

The entry (126 characters):

> Somebody booked Conference Room B for a meeting about meetings, and Brenda brought a cake that said "See you at the next one".

A meeting whose only subject is meetings — booked in a named room, with a named colleague, and a cake that celebrates the cycle continuing. A meeting about meetings has no subject, so nothing could justify holding it: that is how the line kills the meeting.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, 1–200 characters, no trailing newline). Override the output path with `ENTRY_OUTPUT` if the harness needs a different location:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```
